# Itsova 0.12.0 Beta 1

Itsova is a screenshot, screen-recording and annotation tool for KDE Plasma on Wayland. This is the first public beta. Features and shortcuts may change and feedback is welcome.

## Included

- Capture monitors, windows, rectangular selections and saved areas, including multi-monitor layouts.
- Annotate captures, pin them on the desktop, and extract text locally with optional Tesseract OCR.
- Record screens, windows and selected regions as MP4, WebM or GIF.
- Use the Plasma widget, CLI and optional local MCP server.

## Known limitations

- Resizing a window during recording can distort the picture ([#127](https://github.com/m00sfett/Itsova/issues/127)).
- Capture and recording require KDE Plasma on Wayland with KWin. Recordings do not include audio.
- Some multi-monitor and fractional-scaling configurations need further hands-on testing.
- Translations are machine-generated and may contain errors.

See the README for requirements, installation, and privacy details.
